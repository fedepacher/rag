# Fully pinned dependency lock for the `api` service (Dockerfile_api).
#
# DIRECT DEPENDENCIES (everything else below is a transitive of these):
#   fastapi uvicorn gunicorn            -> ASGI app + the server the CMD actually runs
#   pydantic pydantic-settings          -> schemas and the Settings class
#   python-jose cryptography            -> JWT signing (api.app.service.auth_service)
#   passlib bcrypt                      -> password hashing
#   peewee pymysql                      -> MySQL ORM and its driver (peewee.MySQLDatabase)
#   pymongo                             -> prompt queue
#   email_validator                     -> pydantic EmailStr in api/app/schema/user_schema.py
#   python-multipart                    -> OAuth2PasswordRequestForm in user_router.py
#
# bcrypt is held below 4.1 ON PURPOSE. passlib 1.7.4 (2020, last release) cannot detect
# the backend in bcrypt >= 4.1, and CryptContext(schemes=["bcrypt"]).hash() then raises
# "password cannot be longer than 72 bytes" for ANY input, including a single character.
# Unpinned, this file resolves to bcrypt 5.0.0 and every login in the built image fails
# at runtime -- the build stays green, so nothing catches it until a user tries to log in.
# Verified: bcrypt 5.0.0 -> hashing raises; bcrypt 4.0.1 -> passlib detects the backend
# and hashing succeeds.
#
# REMOVED (declared but neither imported by api/ nor required at runtime):
#   pycparser, pydantic_core, starlette  -> transitives of cryptography/pydantic/fastapi
#   websockets, wsproto                  -> uvicorn WebSocket extras; no WS endpoint exists
#   requests                             -> not imported anywhere under api/
#   mysql-connector-python               -> peewee.MySQLDatabase uses pymysql, not this
#   pytest                               -> test dependency, and the repo has no test files
#
# VERIFIED: with this exact set, every module under api/ imports cleanly and passlib
# bcrypt hashing works. api.main itself opens a MySQL connection at import time, so it
# only imports where the database is reachable.
#
